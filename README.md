# The Group Determinant

An interactive page for exploring the group determinant, built for
Math 301 (Representation Theory), Fall 2026.

Pick a group from the dropdown to see its presentation, multiplication
table, the matrix (x_{gh}), and the factorization of

    Θ(G) = det( x_{gh} )_{g,h ∈ G}

into irreducible polynomials, with coefficients written using
ζ_n = e^{2πi/n}. Use the ← and → keys to step through the groups.

## Files

- `index.html` — the page (styled after the course website; uses KaTeX from a CDN).
- `data.js` — all group data and factorizations, generated by `gen.sage`.
- `gen.sage` — the SageMath/GAP script that builds every group, computes
  each irreducible factor Φ_ρ = det(Σ_g x_g ρ(g)), and checks numerically
  that Θ(G) = ± ∏ Φ_ρ^{deg ρ} by random substitution.

## Regenerating the data

    sage gen.sage

(needs SageMath with GAP; takes about 20 seconds). To add a group, add a
model and an `add(...)` line in `gen.sage`.
